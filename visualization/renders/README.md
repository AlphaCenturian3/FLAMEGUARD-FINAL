# Initial renders (illustrations, not evidence)

Four 1280x720 images made by `visualization/gravity_scenes.py` with Blender 5.2.4 LTS. Each carries, inside the image: the scene title, **"ILLUSTRATION ONLY. Not a validated combustion simulation. Not NASA data."**, and "Fuel, oxygen fraction, pressure and airflow are not modelled. Flame shape is an artistic choice."

| File | Scene |
|---|---|
| `earth.png` | Earth, 1 g |
| `mars.png` | Mars, about 0.38 g |
| `moon.png` | Moon, about 0.165 g |
| `microgravity.png` | Microgravity (ISS), about 0 g |

Same camera, wick, colours and background in every image. Only the flame's height stretch changes, from round at 0 g to 2.6x at 1 g, as an artistic mapping. It is **not** a model, **not** validated, and says nothing about real flame size, spread rate or burning rate. Regenerate with the command in `../PLAN.md`.
